# Export to HTML5

To create a web version that works on any browser:

## Steps:

1. In Godot, go to **Project → Export**
2. Add a new **Web** preset
3. Configure:
   - HTML Filename: `index.html`
   - Export Path: `build/web`
4. Click **Export Project**
5. Files will be in `build/web/`

## Host Online:

Upload these files to any web host:
- GitHub Pages (Free)
- Netlify (Free)
- Vercel (Free)
- Your own server

## Play:

Just open `index.html` in any browser - PC, tablet, or phone!

## Note:

Web export may have lower performance than native APK.
